sorreflex writes one line to a text file: a newly coined English word and its one-line definition. The word names the reflex of saying "sorry" when someone else bumps into you — a small social reflex everyone has felt but no word names. The line was picked from 37 candidates by pairwise judging against the brief: the behaviour stated directly, with no example attached, in a word built from two plain English words, sorry and reflex.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 59 characters, a single line, and ends on its strongest beat. The program builds the line from two parts — the coined word, then its definition — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
